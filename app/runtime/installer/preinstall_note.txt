Pre-install requirements

- Internet access is required during installation. The installer downloads Python 3.12.10 x64 and the exact PyTorch 2.10.0 CUDA 13.0 / ONNX Runtime GPU 1.25.1 dependency set from pinned official HTTPS sources, then verifies every file against the OpenDSS hash lock. No network fallback is used after installation.
- The runtime is provisioned transactionally at `%LOCALAPPDATA%\OpenDSS\training-venv-gpu`. A compatible NVIDIA GPU is used automatically. The same environment falls back factually to CPU when a compatible GPU is unavailable.
- A current NVIDIA driver is an external prerequisite for GPU acceleration. Its absence does not prevent CPU training.
- A supported Hamamatsu camera and the official DCAM runtime/driver are external prerequisites for the complete laboratory workflow. The installer does not bundle DCAM.
- Supported National Instruments DAQ hardware and NI-DAQmx are external prerequisites for sorting/trigger output. The installer does not bundle NI-DAQmx.
- The installer includes the required Microsoft Visual C++ x64 runtime and installs or updates it automatically when needed.
- OpenDSS may be launched without Camera or DAQ hardware for training, diagnostics, and packaged-model inspection.
