# OpenDSS Debug Bug Ledger

Ledger format: `1`

The Debug Lead owns this ledger. Workers return evidence to the Debug Lead and do not edit this file directly.

## Active bugs

None.

## Bug record format

Each bug record must contain:

- stable bug ID;
- status and accountable owner;
- expected and observed behavior;
- smallest reliable reproduction;
- observations, hypotheses, and accepted root cause;
- changed files;
- regression and verification evidence;
- protected-asset impact;
- remaining risk and rollback notes;
- exact next action.
